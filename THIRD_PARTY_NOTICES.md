# Third-party notices

The package includes the separate [bliss-guidance-lastfm](https://github.com/chrober/bliss-guidance-lastfm) executable, which depends on [bliss-playlist-guidance-spi](https://github.com/chrober/bliss-playlist-guidance-spi).
[LastMix](https://github.com/michaelherger/LastMix) is optional and is not included in this package. Last.fm data is subject to the [Last.fm API terms](https://www.last.fm/api/tos), independently of the software license.
The release package contains the native provider's version-specific dependency inventory, license texts and supplemental upstream notices in `third-party-licenses/`. The native source archive is linked from `SOURCE.md` in the package.
